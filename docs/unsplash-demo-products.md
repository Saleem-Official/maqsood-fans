# Unsplash demo catalogue seed

Three demo ceiling-fan products were added through the public admin endpoint for testing. Each product has four image URLs, custom pricing, category, finish, blade count, size, reviews count, description, and availability.

The image URLs are direct `images.unsplash.com` CDN hotlinks. Unsplash requires applications to embed the returned CDN URLs directly so views can be tracked. The image CDN URLs were verified with HTTP 200 responses and `image/jpeg` content types.

## Added products

- **Aura Living 52** — Premium, in stock, four images, Rs. 12,800.
- **Nordic Breeze 48** — Designer, in stock, four images, Rs. 9,600.
- **Heritage Air 56** — Natural, sold out, four images, Rs. 14,500.
